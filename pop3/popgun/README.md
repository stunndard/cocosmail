# popgun

[DevelHell/popgun](https://github.com/DevelHell/popgun), through the
[stunndard/popgun](https://github.com/stunndard/popgun) fork
(v0.0.0-20210605125826-7d86a3ec4471), and is maintained here as part of
cocosmail. MIT license, see [LICENSE](LICENSE).
